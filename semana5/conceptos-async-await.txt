Responde con tus propias palabras.

1. Que es una promesa en JavaScript?

Respuesta: Una promesa es un objeto que representa la terminacion o el fracaso de una operacion asincrona. Puede estar pendiente, resuelta o rechazada.

2. Que significa async?

Respuesta: async es una palabra clave que se usa antes de una funcion para indicar que esa funcion siempre devolvera una promesa y puede contener await.

3. Que significa await?

Respuesta: await es una palabra clave que se usa dentro de funciones async para pausar la ejecucion hasta que una promesa se resuelva, y luego devuelve el resultado.

4. Por que fetch devuelve una promesa?

Respuesta: fetch devuelve una promesa porque hace una solicitud HTTP, que es una operacion asincrona. No sabemos cuanto tardara el servidor en responder.

5. Que diferencia viste entre .then() y async/await?

Respuesta: .then() usa callbacks encadenados, mientras que async/await permite escribir codigo asincrono con una sintaxis similar a codigo sincrono, lo que lo hace mas legible.

6. Que hace try en esta practica?

Respuesta: try envuelve el codigo que puede fallar, como la llamada a fetch, y permite capturar errores sin detener la ejecucion del programa.

7. Que hace catch en esta practica?

Respuesta: catch captura cualquier error que ocurra dentro del bloque try y muestra un mensaje alternativo en la interfaz del usuario.

8. Que ruta se usa para cargar mensajes?

Respuesta: /api/mensajes

9. Que ruta se usa para cargar calendario editorial?

Respuesta: /api/calendario

10. Como ayuda async y await a leer mejor el codigo?

Respuesta: async y await ayudan a leer el codigo porque eliminan el anidamiento de callbacks y permiten escribir pasos asincronos en orden secuencial, como si fueran sincronos.
