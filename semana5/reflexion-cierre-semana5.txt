Respuesta:
Al comenzar el curso, mi experiencia con Git y desarrollo web era básica. Trabajar en este proyecto único de Semana 5 en GitHub cambió mi forma de organizarme. Aprendí a usar ramas: main para los docentes y mi rama personal angeli_florez para mis avances. Cada clase empecé con git pull --ff-only para actualizar main y luego git merge main para traer los cambios a mi rama. Los commits con mensajes claros me ayudaron a registrar cada avance. En el frontend construí un HTML con secciones y un tablero de mensajes que se carga dinámicamente con JavaScript usando fetch, async y await para consumir la API. En el backend usé Node.js con Express para crear rutas como GET /api/mensajes y servir datos JSON. Implementé un login pedagógico con credenciales demo y un middleware simple para proteger la ruta de revisión editorial. Aprendí sobre difusión responsable, revisión de fuentes, consistencia comunicativa y lenguaje responsable y no estigmatizante. Todo esto me mostró que la tecnología puede apoyar la participación ciudadana y una cultura de paz cuando se usa con responsabilidad y documentación clara.
