Escribe una reflexión de 8 a 10 líneas respondiendo:

¿Por qué conectar el frontend con el backend ayuda a que un mini-sitio comunitario mantenga información dinámica, actualizable y útil para la comunidad?

En tu respuesta menciona al menos cinco de estas ideas:

- integración Frontend-Backend
- consumo de la API propia
- mensajes dinámicos
- frontend
- backend
- API
- JSON
- fetch
- async
- await
- render dinámico
- comunicación responsable
- revisión de fuentes
- consistencia comunicativa
- moderación editorial básica
- participación ciudadana
- cultura de paz

Respuesta:
La integración Frontend-Backend permite que el mini-sitio comunitario muestre información dinámica y actualizable sin modificar el HTML cada vez. El frontend usa fetch() para consumir la API propia del proyecto, que expone rutas como GET /api/mensajes y devuelve datos en formato JSON. Gracias a async y await, el frontend espera la respuesta del servidor y luego realiza un render dinámico de los datos en el tablero. Esto facilita la comunicación responsable porque la comunidad siempre ve la información más reciente. Además, la revisión de fuentes y la consistencia comunicativa se mantienen desde los datos base, mientras que la moderación editorial básica asegura que cada mensaje sea apropiado. Esta arquitectura fortalece la participación ciudadana y promueve una cultura de paz al permitir que la información comunitaria sea verificable, clara y accesible para todas las personas.
