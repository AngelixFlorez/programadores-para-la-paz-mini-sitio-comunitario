2. Accesibilidad mínima

¿Los títulos son comprensibles y las secciones están separadas?

Respuesta: Sí, cada sección tiene un encabezado claro y están visualmente separadas.

3. Legibilidad

¿Los textos se pueden leer con facilidad?

4. Contraste suficiente

¿El texto se distingue del fondo?

Respuesta: Sí, el contraste entre texto y fondo es suficiente para leer sin esfuerzo.

6. Lenguaje claro

¿Los mensajes son comprensibles para una comunidad general?

Respuesta: Sí, usan lenguaje sencillo y directo sin tecnicismos innecesarios.

7. Organización visual coherente

¿Las tarjetas mantienen una estructura similar?

Respuesta: Sí, todas las tarjetas siguen el mismo patrón: título, cuerpo, etiquetas y fuente.

8. Seguridad visual

¿La vista pública evita saturación, confusión o exposición innecesaria?

Respuesta: Sí, solo se muestran campos útiles para la comunidad; el id queda oculto.
