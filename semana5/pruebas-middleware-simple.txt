Prueba 4: Token incorrecto

Explica qué debería pasar si el token no coincide con el esperado.

Respuesta: El middleware verifica que el token sea "token-demostracion-clase-24". Si no coincide, responde con 403 y el mensaje "Acceso denegado. El token de demostración no es válido."

5. ¿Qué hace el middleware simple?

Respuesta: Intercepta la solicitud a GET /api/revision-editorial, verifica el token en el encabezado Authorization y permite o deniega el acceso.

6. ¿Por qué este middleware no debe confundirse con seguridad real?

Respuesta: Porque usa un token fijo y predecible almacenado en localStorage, lo cual no es seguro para producción.

7. ¿Qué aprendiste sobre rutas públicas y rutas protegidas?

Respuesta: Las rutas públicas son accesibles sin autenticación, mientras que las protegidas requieren un token o credencial para garantizar que solo personas autorizadas accedan a la información.
